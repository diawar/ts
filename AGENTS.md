# Репозиторий проекта

По указанию пользователя от 13 ноября 2026 года единственный репозиторий для отправки изменений TenderSearch — https://github.com/diawar/ts.

- Все push, публикации кода и pull request этого проекта направлять только в `diawar/ts`.
- Перед отправкой проверять фактический push URL. Для `origin` использовать `https://github.com/diawar/ts.git`.
- Не отправлять изменения в прежний `diawar/tendersearch` или другие репозитории.
